# Общий сеанс — совместный просмотр

Статический сайт: комнаты по ссылке, синхронная пауза/запуск/перемотка, чат и реакции.
Сервер не нужен — сайт лежит на GitHub Pages, синхронизацию делает Firebase Realtime Database (бесплатный тариф Spark).

Что можно смотреть:
- **YouTube** — по любой ссылке (youtube.com/watch, youtu.be, shorts, live);
- **прямые ссылки на видео** — `.mp4`, `.webm`, `.m3u8`;
- **свой файл** — у каждого одинаковый файл на устройстве, видео не пересылается.

Файлы проекта:

| Файл | Что это |
|---|---|
| `index.html` | страница |
| `style.css` | оформление |
| `app.js` | логика: комнаты, синхронизация, чат |
| `config.js` | **сюда вставляются ключи вашего Firebase** |
| `database.rules.json` | правила доступа к базе — вставляются в консоли Firebase |

---

## Шаг 1. Создайте проект Firebase

1. Откройте https://console.firebase.google.com и войдите Google-аккаунтом.
2. **Create a project** → придумайте имя (например, `kinoseans`) → Google Analytics можно выключить → **Create project**.

## Шаг 2. Создайте базу данных

1. Слева **Build → Realtime Database → Create Database**.
2. Регион — **Belgium (europe-west1)** (ближе всего к Узбекистану из доступных).
3. Режим — **Start in locked mode** → **Enable**.
4. Откройте вкладку **Rules**, удалите всё, что там есть, вставьте содержимое файла `database.rules.json` и нажмите **Publish**.

## Шаг 3. Включите анонимный вход

Зрителям не нужно регистрироваться: сайт сам выдаёт каждому анонимный аккаунт. Это нужно, чтобы правила базы работали.

**Build → Authentication → Get started → Sign-in method → Anonymous → Enable → Save.**

## Шаг 4. Скопируйте ключи в `config.js`

1. Шестерёнка вверху слева → **Project settings**.
2. Внизу, в блоке **Your apps**, нажмите значок **`</>`** (Web), введите любое имя, **Firebase Hosting не отмечайте** → **Register app**.
3. Появится код с `const firebaseConfig = { ... }`. Перенесите значения в `config.js`:

```js
export const FIREBASE_CONFIG = {
  apiKey: "AIza...",
  authDomain: "kinoseans.firebaseapp.com",
  databaseURL: "https://kinoseans-default-rtdb.europe-west1.firebasedatabase.app",
  projectId: "kinoseans",
  appId: "1:1234567890:web:abc123"
};
```

Если в показанном коде нет `databaseURL`, возьмите адрес со страницы **Realtime Database** (он сверху, над данными).

Ключи из `config.js` не секретные — их видит любой браузер. Данные защищают правила из шага 2.

## Шаг 5. Выложите сайт на GitHub Pages

1. Зарегистрируйтесь на https://github.com (если ещё нет аккаунта).
2. **New repository** → имя, например `kino` → **Public** → **Create repository**.
3. **uploading an existing file** → перетащите все файлы проекта → **Commit changes**.
4. В репозитории: **Settings → Pages → Branch: `main`, папка `/ (root)` → Save**.
5. Через 1–2 минуты сайт будет по адресу `https://ВАШ-ЛОГИН.github.io/kino/`.

## Шаг 6. Разрешите домен в Firebase

**Authentication → Settings → Authorized domains → Add domain** → впишите `ВАШ-ЛОГИН.github.io` (без `https://` и без `/kino`).

Готово. Откройте сайт, нажмите **Создать комнату**, затем **Скопировать ссылку** и отправьте её друзьям.

## Проверить у себя на компьютере (необязательно)

Если открыть `index.html` двойным щелчком, страница не заработает: браузеры не запускают такие скрипты с диска. Запустите простой локальный сервер в папке проекта:

```
python -m http.server 8000
```

и откройте http://localhost:8000 (адрес `localhost` уже разрешён в Firebase по умолчанию).

## Как это работает

- Управлять может любой в комнате: пауза, запуск и перемотка у одного сразу повторяются у всех.
- Если кто-то отстал, плеер его догоняет: небольшую разницу — чуть ускоряя или замедляя видео, большую — перемоткой.
- Время сверяется по часам сервера Firebase, поэтому разница в часах на телефонах не мешает.
- Если браузер не дал запустить видео сам (так бывает до первого нажатия на странице), появится кнопка **«Присоединиться к просмотру»**.

## Ограничения

- **Бесплатный тариф Firebase** — до 100 одновременных подключений (каждая открытая вкладка = 1). Для компании друзей с запасом.
- **YouTube**: некоторые видео владелец запрещает показывать на других сайтах — такое видео не запустится, сайт об этом скажет.
- **Прямые ссылки**: ссылка должна вести на сам видеофайл, а не на страницу с плеером. Для `.m3u8` сервер видео должен разрешать воспроизведение с других сайтов (CORS).
- **Свои файлы**: браузеры уверенно играют MP4 (H.264) и WebM. MKV и AVI часто не открываются — их можно перекодировать в MP4, например в HandBrake.
- Старые комнаты остаются в базе. Почистить можно в консоли: **Realtime Database → Data → `rooms` → удалить**.
